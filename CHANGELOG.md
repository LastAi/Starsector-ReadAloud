# Changelog

## 0.2.0 Alpha
- New "speech" choice under "Who reads what": only what characters say (text in quotation marks) is read, and the narrator stays silent. Works with the system voice and AI Voices. Requested by Rook999.
- In "speech" mode, a short pause where narration between two quotes is skipped, so separate lines don't run together. Set its length (or 0 for none) under "Pause for skipped narration".

## 0.1.1 Alpha
- The credit symbol (¢) is read as "credits" instead of "cents".

## 0.1.0 Alpha
- First public release.
